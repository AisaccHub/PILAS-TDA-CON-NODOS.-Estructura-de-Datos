# PILAS-TDA-CON-NODOS.-Estructura-de-Datos
Es un sistema que organizara ordenes por pilas, bajo la lógica del LIFO, sumándole también una interfaz grafica simple.
Esta interfaz grafica solo funcionara para usar las funciones que creamos en el Codigo de pilas, Node, Vinyl, etc.
Este sistema utiliza los principios de nodos para almacenar datos simples(como numeros, objetos, etc), estos nodos usan un next con un puntero directo al numero de abajo.
El "push" funcionara para apilar los datos hacia adelante con un "push".
El"pop" desapilara los datos en la pila.
El "top/peek" servira para consultar que nodo esta en la parte superior o devolver el valor a la parte superior de la pila.
El "is_empty" funcionara para saber si la pila esta vacia o el puntero tope, si se encuentran en estado("NULL")
